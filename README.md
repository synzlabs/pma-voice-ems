# pma-voice for EMS Job Simulator

By **Reborn Scripts** · [reborn-scripts.com](https://reborn-scripts.com)

Download this version of pma-voice to make the EMS radio of **EMS Job Simulator** fully work, including talking to all frequencies at once (EMS broadcast).

## Install

1. Download `pma-voice.zip` from this repository (do not use the green **Code > Download ZIP** button).
2. Extract it: you get a folder called `pma-voice`.
3. Replace your current `pma-voice` folder with it. The folder **must be named exactly `pma-voice`**, otherwise the radio will not find it.
4. Restart the server.

Based on [pma-voice](https://github.com/AvarianKnight/pma-voice) by AvarianKnight (MIT license, included in the zip).
